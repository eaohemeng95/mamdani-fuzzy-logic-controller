# Mamdani Fuzzy Logic Controller for DC Motor Speed Control

## 1. Project Overview

This project presents the design and simulation of a Mamdani-type Fuzzy Logic Controller using MATLAB and Simulink.

The controller is developed for DC motor speed regulation using fuzzy logic principles and a PID-based control structure.

The project explores the application of fuzzy logic in improving control system performance and achieving accurate speed tracking.

## 2. Project Objectives

- Design and implement a Mamdani Fuzzy Logic Controller.
- Develop a DC motor control system in MATLAB/Simulink.
- Implement fuzzy logic-based PID control.
- Evaluate the system response through simulation.
- Examine the effectiveness of fuzzy control for motor speed regulation.

## 3. Tools and Technologies

- MATLAB
- Simulink
- Fuzzy Logic Toolbox

## 4. Control System Architecture

The Simulink model incorporates the reference input, feedback control loop, fuzzy logic controller and PID control structure.

The fuzzy controller uses its defined membership functions and rule base to determine the appropriate control adjustments.

## 5. Fuzzy Logic Controller Design

The controller is based on the Mamdani fuzzy inference approach.

The design involves:

- Definition of input and output linguistic variables.
- Membership function configuration.
- Development of the fuzzy rule base.
- Fuzzy inference and aggregation.
- Defuzzification to obtain crisp control outputs.
